# SIM/TOP: CPU_TOPのDMAポート(手順2.6)

[English](README.md)

`tb_CPU_TOP.sv`は`RTL/CPU/TOP`の`CPU_TOP`をDMAポート(AXI4-Liteスレーブ)で試す。Verilatorだけ(`--timing`)。メモリバスは
`SIM/OCD`の`AXI4_RAM`(0x8000_0000、`dma_prog.S`入り)へ、周辺バスはその`AXIL_RAM`(0x1200_0000)へ。コアは`dma_prog.S`を
動かす: 0x8000_1000へ1語書き(D$でダーティ、メモリはまだ0)、0x8000_2000のDMAの語をD$のラインで待ち、0x8000_2008を
0x8000_3000へ写す。ベンチはDMAポートで:

1. 0x8000_1000を読む: コアの語をD$から(一貫性)。
2. 0x8000_2008を分割して書く(ストローブ0x3c: 2 + 2バイト、0x81: 1 + 1)。
3. ストローブなしで書く(応答だけで何も書かない)。
4. コアが待つ語0x8000_2000を書く。
5. 0x8000_3000を読む: コアが写した分割書き込みの結果(両方の書き込みが見えた)。
6. デバイスの語(0x1200_0010、周辺バス)を書いて読み、0x0を読む(デバイスなし: SLVERR)。

```bash
./run_top.sh
```
